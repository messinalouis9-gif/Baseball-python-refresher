# How to help

Thanks for wanting to improve this. Beginners are welcome; that's who it's for.

## Easy ways to help
- **Spotted a mistake or a confusing step?** Open an Issue (the Issues tab above). Give the step number and what tripped you up.
- **Have a better way to write a step?** Open an Issue with your version, or send a pull request.
- **Want to add a section?** Ideas: SQL with SQLite, R, hitting and batted-ball data, defense, Excel to Python.

## Rules for new steps
1. Use only free, public data (Baseball Savant, pybaseball, FanGraphs or Baseball Reference exports). No team or private data.
2. Follow the format: a short title, where to type it, the code, and a one-line tip.
3. Run the whole notebook with Kernel > Restart & Run All before submitting, so every step still works in order.
4. Explain in plain English. Assume the reader has never coded.
5. If AI helped you write it, say so in your pull request. That's fine; just test it.

All changes are reviewed before they're added.
